# MX Grid – vydání

Multiplayerový motokrosový simulátor pro Windows PC. Tento repozitář obsahuje jen vydání hry, zdrojový kód je jinde.

## Instalace

1. V sekci [Releases](https://github.com/stovajs/mx-grid-releases/releases/latest) stáhněte `MxGrid-Setup-<verze>.exe`.
2. Spusťte instalátor. Instaluje se jen pro aktuálního uživatele a nepotřebuje práva správce.
   Instalátor zatím není podepsaný, takže Windows SmartScreen může varovat: zvolte *Další informace → Přesto spustit*.
3. Hru spouštějte zástupcem *MX Grid* v nabídce Start.

## Aktualizace

Zástupce spouští launcher. Ten při každém startu zkontroluje novou verzi a stáhne jen změněné soubory.
Bez připojení k internetu se spustí nainstalovaná verze.

Vydání `objects` obsahuje soubory pro launcher, ručně je stahovat není potřeba.

## Požadavky

- Windows 10/11 (64 bit)
- grafická karta s DirectX 12
- doporučen gamepad kompatibilní s Xboxem (klávesnice funguje také)
